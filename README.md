# 🌍 Travel Currency Converter

Telegram-бот для мандрівників, який дозволяє отримувати актуальну інформацію про погоду, переглядати курси валют і конвертувати грошові суми за допомогою зовнішніх API.

Проєкт розроблений на Python та використовує Telegram Bot API для взаємодії з користувачем, OpenWeatherMap для отримання погодних даних і ExchangeRate-API для отримання курсів валют.

## 🌐 Про проєкт

**Travel Currency Converter** — це Telegram-бот, створений для допомоги мандрівникам у повсякденних ситуаціях під час подорожей.

За допомогою бота користувач може дізнатися поточну погоду в налаштованому або обраному місті, переглянути курси популярних валют і швидко розрахувати еквівалент грошової суми в іншій валюті.

Бот отримує інформацію із зовнішніх API, обробляє відповіді та повертає результати у вигляді зрозумілих текстових повідомлень.

## ✨ Основні можливості

### 🌤 Перегляд погоди

- Отримання поточної погоди для налаштованого міста.
- Можливість перевірити погоду в іншому місті.
- Відображення температури та відчутної температури.
- Відображення опису погодних умов, вологості та швидкості вітру.
- Формування рекомендацій залежно від погоди.
- Виведення повідомлень про помилки під час отримання даних.

### 💱 Конвертація валют

- Конвертація заданої суми між двома валютами.
- Підтримка кодів валют у форматі ISO 4217, наприклад USD, EUR, UAH.
- Перевірка коректності введеної суми.
- Отримання курсу через ExchangeRate-API.
- Відображення розрахованої суми, обмінного курсу та часу останнього оновлення даних.

### 📊 Перегляд курсів валют

- Отримання курсів відносно вибраної базової валюти.
- Відображення курсів UAH, EUR, USD, GBP, PLN та CZK, якщо відповідні дані доступні.
- Відображення часу останнього оновлення курсів.

## 🏗️ Архітектура системи

Система побудована за принципом взаємодії Telegram-бота із зовнішніми вебсервісами через HTTP API.

![Архітектурна схема Travel Currency Converter](architecture.png)

### Взаємодія компонентів

1. Користувач надсилає команду або натискає кнопку в Telegram.
2. Telegram Bot API передає повідомлення програмі через метод `getUpdates`.
3. Python-застосунок аналізує команду та визначає потрібну операцію.
4. Для отримання погоди програма надсилає HTTPS-запит до OpenWeatherMap API.
5. Для конвертації або перегляду курсів програма звертається до ExchangeRate-API.
6. Отримані відповіді обробляються, перевіряються та форматуються.
7. Результат надсилається користувачу через метод `sendMessage` Telegram Bot API.
8. У разі помилок програма формує відповідне повідомлення та записує технічну інформацію до журналу.

### Протоколи взаємодії

- **HTTPS** — обмін даними із зовнішніми API.
- **REST API** — взаємодія з Telegram Bot API, OpenWeatherMap та ExchangeRate-API.
- **JSON** — формат передавання даних між програмою та API.

У поточній реалізації бот отримує оновлення через періодичні запити `getUpdates` (long polling). WebSockets і MQTT не використовуються.

## 💬 Команди бота

| Команда | Опис | Приклад |
|---|---|---|
| `/start` | Вітальне повідомлення та список можливостей | `/start` |

| `/weather` | Погода для міста за замовчуванням | `/weather` |

cd Travel-Currency-Converter
```

Заміни `<URL_ВАШОГО_РЕПОЗИТОРІЮ>` на адресу власного GitHub-репозиторію.

Або, якщо залежності вже внесені до `requirements.txt`:

```

## ⚙️ Налаштування

Для роботи бота необхідно налаштувати змінні середовища.

Створи файл `.env` у кореневій папці проєкту:

```dotenv
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
WEATHER_API_KEY=your_openweathermap_api_key
WEATHER_CITY=Kropyvnytskyi
EXCHANGE_RATE_API_KEY=your_exchange_rate_api_key
```

### Опис змінних

| Змінна | Призначення |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен Telegram-бота |
| `WEATHER_API_KEY` | API-ключ OpenWeatherMap |
| `WEATHER_CITY` | Місто для прогнозу погоди за замовчуванням |
| `EXCHANGE_RATE_API_KEY` | API-ключ ExchangeRate-API, необов'язковий для поточного резервного режиму |

Якщо `EXCHANGE_RATE_API_KEY` не заданий, програма використовує endpoint `open.er-api.com` без ключа. Доступність і можливості цього endpoint залежать від умов сервісу.

Файл `.env.example` може містити ті самі назви змінних із демонстраційними значеннями, але без справжніх секретів.

## ▶️ Запуск

Після встановлення залежностей і налаштування `.env` запусти бота:

```bash
python main.py
```

Якщо налаштування правильні, у журналі з'явиться повідомлення про запуск.

Відкрий Telegram, знайди свого бота та надішли команду:

```text
/start
```

Після цього можна користуватися командами та кнопками меню.

## 🔒 Безпека

- Не додавай файл `.env` до GitHub.
- Не публікуй токен Telegram-бота та API-ключі.
- Додай `.env` і `venv/` до `.gitignore`.
- Не зберігай секретні ключі безпосередньо в коді.
- Використовуй тайм-аути для HTTP-запитів.
- Перевіряй дані, які вводить користувач.

Приклад `.gitignore`:

```gitignore
.env
venv/
__pycache__/
*.py[cod]
```
