# Travel Currency Converter

Вебдодаток для мандрівників, який допомагає визначити приблизне місцезнаходження користувача або переглянути дані для обраного міста, дізнатися поточну погоду та конвертувати валюту за актуальним курсом. Основні дані отримуються через зовнішні API.

## Архітектура системи

![Архітектурна схема Travel Currency Converter](architecture.png)

### Взаємодія компонентів

1. Користувач відкриває вебінтерфейс у браузері.
2. Frontend надсилає HTTP/HTTPS-запити до бекенду на Flask.
3. Бекенд звертається до зовнішніх сервісів:
   - **ipapi.co** — визначення країни та орієнтовного міста за IP;
   - **ExchangeRate-API** — отримання курсів валют;
   - **OpenWeatherMap** — отримання поточних погодних даних.
4. Бекенд обробляє відповіді й повертає дані інтерфейсу.
5. Тимчасові результати за потреби можуть зберігатися в пам'яті або кеші. API-ключі зберігаються в локальному файлі `.env`, який не додається до репозиторію.

**Протоколи:** HTTP/HTTPS REST API. WebSockets та MQTT для початкової версії не потрібні.

## Технологічний стек

- **Python** — основна мова програмування.
- **Flask** — вебфреймворк для бекенду.
- **HTML та CSS** — структура й оформлення вебсторінки.
- **JavaScript** — інтерактивність інтерфейсу за потреби.
- **ExchangeRate-API** — курси валют.
- **ipapi.co** — геолокація за IP.
- **OpenWeatherMap** — дані про погоду.
- **Git та GitHub** — контроль версій і зберігання коду.

## Налаштування

1. Клонуйте репозиторій.
2. Створіть і активуйте віртуальне середовище Python.
3. Встановіть залежності після додавання `requirements.txt`.
4. Скопіюйте `.env.example` у `.env` та додайте власні ключі API.
5. Запустіть застосунок командою, описаною в інструкції після реалізації бекенду.

> Примітка: API-ключі та точні обмеження безкоштовних тарифів залежать від умов відповідних сервісів. Не публікуйте секретні ключі в репозиторії.


## Telegram Bot Integration

The project includes a Telegram bot that retrieves current
weather data from OpenWeatherMap and sends it to the user.

### Features
- `/start` — displays a welcome message.
- `/weather` — returns current weather for the configured city.
- Error handling for API and network failures.

### Configuration
1. Install dependencies:
   `pip install requests python-dotenv`
2. Copy `.env.example` to `.env`.
3. Add your API key and Telegram bot token to `.env`.
4. Run the application:
   `python main.py`

Never commit the `.env` file or expose API keys.
